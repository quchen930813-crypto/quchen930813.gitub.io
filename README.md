# 个人主页

一个简洁、现代的单页个人主页，使用原生 HTML、CSS 和 JavaScript 编写，无需构建工具、后端或第三方服务。

## 文件结构

```
.
├── index.html        # 页面结构与所有占位文字
├── style.css         # 样式、配色、响应式布局
├── script.js         # 移动端菜单、滚动淡入、头像兜底等交互
├── images/
│   └── avatar.jpg    # 本地头像占位图（可直接替换）
└── README.md
```

## 本地预览

**方式一：直接打开**

双击 `index.html`，用浏览器打开即可。

**方式二：本地静态服务器（推荐，避免个别浏览器的本地文件限制）**

在当前目录执行：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

也可以使用 VS Code 的 Live Server 插件。页面为纯静态文件，不需要安装依赖。

## 替换头像

1. 准备一张竖版照片，建议比例为 **4:5**（例如 800×1000 像素），主体居中。
2. 将图片命名为 `avatar.jpg`，覆盖 `images/avatar.jpg` 即可，无需修改代码。
3. 也可以保留原文件名、换用其他格式，此时把 `index.html` 中 `<img id="avatar" src="images/avatar.jpg" ...>` 的 `src` 改成新路径。

如果图片缺失或加载失败，页面会自动显示文字头像「你」作为兜底（逻辑在 `script.js` 中，可自行修改或删除）。建议同时更新 `<img>` 的 `alt` 文字。

## 修改文字与链接

所有内容都是占位，直接在 `index.html` 中搜索并替换：

| 位置 | 占位内容 |
| --- | --- |
| 姓名 | `你的名字`（浏览器标题、导航、首屏、页脚） |
| 简介 | 首屏段落，以及「关于我」区块 |
| 学习 / 工作方向 | 首屏的信息栏与「关于我」的列表 |
| 作品 | 三个 `<article class="card">`：标题、简介、标签、链接 |
| 联系方式 | `mailto:hello@example.com`、`github.com/yourname`、`weibo.com/yourname` |
| 项目链接 | `https://example.com`（作品卡片上的「查看项目」） |

替换后可全局搜索 `example.com`、`yourname`、`你的名字` 检查是否还有遗漏。

## 调整样式

配色、字体、圆角和内容最大宽度集中在 `style.css` 顶部的 `:root` 变量中，例如：

```css
:root {
  --bg: #f7f6f2;      /* 页面背景 */
  --ink: #16171a;     /* 主文字 */
  --accent: #0f766e;  /* 强调色 */
  --container: 1100px;/* 内容宽度 */
}
```

修改这几个变量即可整体换色，不需要逐条改样式。

## 已包含的功能

- 桌面端与手机端自适应布局（断点 900px / 760px / 480px）
- 移动端折叠导航，支持 Esc 关闭、点击链接后自动收起
- 页面元素进入视口时淡入，并尊重系统的「减少动态效果」设置
- 头像加载失败时显示文字占位
- 键盘可访问：跳转链接、可见焦点样式、语义化标签

## 说明

页面不依赖任何收费 API、数据库或后端服务，也不包含登录、注册和后台上传功能。部署时把整个目录上传到任意静态托管（GitHub Pages、Netlify、对象存储等）即可。
